# 文风

何时读：执笔、自比与首章认可涉及文风取舍时；作者要选定或切换内置文风档案、提供对标小说提取档案时。

本页维护文风档案的选择、生效和迁移边界；具体声线由生效档案维护。作者约定、固定章纲及任务预算约束当前项目，档案不得另造人物、资源、情节、篇幅验收或统计配额。[创作与自比](craft.md) 提供因果与诊断方法，不另设平行声线规范。

## 生效档案与优先级

写作派工（write/repair/redesign）的 guides 自动带本页与实际档案文件的绝对路径。内置档名由 `contracts.resolve_style_profile` 解析，交付层另检查项目自定义文件；材料 `style.profile` 表示契约解析出的内置档名，自定义文件是否生效以 guides 路径为准。文学档案按以下顺序选取，机械锚点另见下节：

1. **作者确认的自定义档案**：项目根 `PROJECT/style-profile.md` 存在时，交付层以它完整替换内置文学档案，不隐式继承未下发的内置条目。作者确认后才放入此路径；文件存在本身不是确认凭证，确认由主控按作者真实决定落实。
2. **契约选定的内置档案**：契约字段 `style_profile`（枚举＝内置目录名）。
3. **引擎默认档案**：`市井修仙`。作者未选择时的缺省。

## 选择与切换

- **逐门开书**：作者口头选定后，约定激活即由主控登记——`recontract --file 补丁.json --patch --source 作者原话`（文件如 `{"style_profile": "账房掌门"}`）。参数级变更：直接生效，不建 pending_contract、不触发重写。
- **自备约定**：`init --contract 约定.json` 直接带 `style_profile` 字段，缺省按默认档。
- **运行中换档**：同一 patch 命令。换档改变声线对照与未认可项目的注册锚点；机械基线认可后源自本书已认可正文本身（最近已认可章节中位，见下节），换档不动它——自定义档案本就不注册机械形状，声线层与数值层各自跟随自己的来源。
- 内置档选定**不需要**复制任何文件；`PROJECT/style-profile.md` 只用于 style-distill 提取的自定义档案。

## 执笔读什么

- 生效文学档案以 guides 下发的文件为准，材料 `style.profile` 仍是内置选择名。首章与新定声线的章节完整读档案；常规章读一句话定位、MUST/AVOID 与高频短语口癖清单，再按本章内容补读相关维度小节（对白重的章读对话风格，换景章读场景与章节结构）。
- 档案例句是参考小说原文，只作对照样本；机械基线按已认可章节滚动（首章只作开卷参照，[文风](narrative.md#文风)），档案负责文学层面的声线取舍，二者并行不互相替代。

## 自比比什么

`self_check` 的文风部分对照当前场景适用的档案条目，给具体依据，不用空泛结论：

- 声线：叙述口吻（视角距离、插评习惯）与人物声纹是否贴档案；
- 口癖：句式节奏、称谓系统、语气词与高频短语是否用在该用之处；
- MUST/AVOID：核对适用条目，说明实际偏离及理由，不把全档条目逐章抄成第二份清单；
- 偏离：静章、争吵、死亡等处境允许偏离常规声线（[执笔](craft.md#执笔)），说明处境理由即可，不为凑档案硬贴。

创作判断依据见 [自比与细节依据](craft.md#自比与细节依据)，不新增评分项。

## 首章认可

首章定调对照生效档案：视角距离、句段节奏、对白密度、口癖与 MUST/AVOID 是否贴近，偏离处随首章说明。作者认可后 `style_anchor` 仍按现行机制登记首章样本：认可定调＝声线与气质承接，样本作为开卷参照；数值基线随后由已认可章节滚动接管（见下节），档案继续作为声线判断依据。

## 基线来源：开卷参照与全书常态

代理指标的数值基线按两段式取值：

- **开卷参照**：尚无已认可章节可用时，基线取作者认可首章的实测（`style.current_anchor`，报告标 `origin=pilot`）；认可前取契约 `style_profile` 的注册锚点（`origin=default`，内置档名缺失或未知回落引擎默认档）。
- **全书常态**：已认可章节积累后，基线改为最近已认可章节（当前分支，就近取 `DEFAULTS['style_baseline_window']`＝5 章）逐指标取中位（`origin=rolling`，`basis` 标所用章号）。开卷处境值（如夜戏低对白）不再终身充当全书 expect；中位吸收单章处境（静章/争吵章），又不至于追不上全书演变。
- 每次提交与每次派工都从已入库正文现算（metrics 从不落库），旧库升级后下一章起 expect 平滑切到滚动中位，无存量迁移。
- 自定义文学档案不注册机械形状，也不改变上述取值链。例如契约选账房掌门后放入自定义文件，文学声线用自定义档，机械锚仍按上述规则取值。代理指标与文学档案是两条来源链。

## 语料统计与迁移边界

共同计数口径登记在 [语料事实](corpus-facts.md)。档案中的源书人物、地名、机构、货币和章号用于解释样本，不进入当前小说事实；迁移时使用本书已成立的人物及设定，不凭参考档案增加组织或机制。统计表描述源语料，不能规定当前章幅、场景人数、标点数量或固定节拍；当前篇幅使用冻结 word_budget，数量与时钟按事实协议核算。样本无法复算的章均不作为新的硬参数。

各档第三节保留特征与例句，第七节集中维护迁移条目；前者不再另列一套执行规则。条目中的题材装置只在本书具备相应设定时采用，场景处境允许调整表达，不为凑样本频次新增事件或人物。

## 新增内置档案

1. 需要新提取时，先在当前宿主发现并读取外部 `style-distill` 技能，按其实际入口处理参考小说；不假定个人安装路径。未安装或原语料不可用时保留已有档案并说明缺口，不编造提取结果。新档案经作者确认后才供写作项目使用。
2. 确认后的档案放入 `references/styles/<名>.md`：纯档案内容（一句话定位、语料事实、八大维度、高频短语与口癖、风格演变、章节标题风格、仿写规范 MUST/AVOID），不含机制小节，不互相引用。
3. 引擎注册表 `contracts.STYLE_CATALOG` 加一行：`'<名>': {'file': 'styles/<名>.md', 'anchor': {…}}`。锚点数值取档案「语料事实」：`han` 固定 2000（可比性门槛，非文风形状）；档案未声明的句级指标沿用通用值。注册表是引擎侧唯一数值源，不解析档案正文取数。
4. 可选：把 `DEFAULTS['style_profile_default']` 换成新档名作为引擎默认。
5. 多部对标小说由 style-distill 各出一份档案，不合并提取；项目内换档或换自定义档案由作者决定后整份替换，不改写档案内容。档案是作者侧参考材料，不进数据库事实，不改约定对齐字段；开书文风门从档案归纳 `voice`/`style_traits`/`tone` 时仍走正常开书协议，`style_guard`/`style_window` 与两段式基线的机械语义不变。
