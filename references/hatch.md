# 创意工具箱

何时读：开书逐门选择要换组、方案同质化，或卷规划需要中期转折时。

## 使用边界

本页提供构思方法，方案格式和门序见 [逐门开书](opening.md)，创作判断见 [创作与自比](craft.md)。已选方向和任务交付要求是约束；具体方法只用于当前构思，不变成所有章节通用的情节门槛。

默认方向（起点/番茄男频长篇网文）及其"默认而非硬要求"的边界见 [逐门开书](opening.md#默认方向起点番茄男频长篇网文)，此处不复制第二份；方法是把方案推离已有方案的杠杆，不是替换方向的借口。

方法用于**把下一个方案推离已有方案**，只用来想，不写进作者可见方案。同一门换组后，应能指出推进方式与代价的实际差别，不能只换措辞或附上方法自评。

## 设定生成方法

方法清单在 `contracts.LENSES`（v3 起是 **12 条网文设定生成法**，每条都写明"必须产出什么"），当轮方法以任务简报中的 `lens_brief` 为准——简报里这一行仍叫"本轮创意透镜"，下表按方法名列出；下表用于理解和自检。采用某方法时检查它**产出了什么**，不要求方法全部出现，也不要求每次选择都支付不可逆代价。

| 方法 | 要点 | 采用时检查 |
|---|---|---|
| 金手指倒推 | 先定主角独一份的优势，再让世界的资源、势力与等级围着它长出来：升级材料、克制它的对手、想抢它的组织都要能从世界里持续产出；只给一个外挂不算 | 写清优势是什么、每次使用要什么、世界里有谁在供料、谁在抢它，以及它开篇三章第一次怎么用上 |
| 等级闭环 | 把力量做成读者能预期的台阶（境界/段位/星级/职位），每级都有明确的升级条件与可量化资源；条件写在世界里，读者随时能答"下一步要什么" | 列出三级台阶：每级的名字、升级条件、拿到什么、卡在哪，以及谁在把守这个门槛 |
| 对手换图 | 按舞台层级排对手（村镇→城池→宗门→王朝→界域），每次胜利把舞台推高一级，新舞台自带新资源与新规则；靠误会或临时加设定维持的梯度不算 | 写出前三级对手、每级挡住的具体利益，以及主角胜利后换到哪张图、图上有什么新东西 |
| 硬通货 | 世界必须有一种可记账的稀缺资源（灵石/贡献点/积分/信用/丹药），谁分配它谁就有权，冲突围绕分配权与获取渠道展开；只当背景名词不算 | 写清货币名、来源、稀缺点、分配者，以及主角第一次为它出手的场合与代价 |
| 身份马甲 | 主角在多个势力里有不同身份，制造扮猪吃虎、打脸与信息差；每个身份都要带暴露风险，身份之间不能互相打架 | 写出至少两个身份、各自的用处、暴露会失去什么，以及第一次差点暴露的场合 |
| 套路反打 | 在类型固有桥段上翻一层：读者熟悉的那一步照走，代价或结果反过来；为反而反、让读者看不懂规则不算 | 先写清被反打的那条套路，再写反转后谁吃亏、爽点落在哪一句 |
| 代价上限 | 主角的优势必须在开篇就带上可见的代价与明确的上限，代价改变后续抉择；后期靠临时削弱或加强来维持平衡不算 | 写清代价的具体形态、上限在哪，以及它如何限制下一次选择 |
| 爽点倒推 | 从读者要的兑现节奏倒推设定：短线兑现密度、章末钩与卷内高潮位置先定，设定为节奏服务；设定好看而节奏空转不算 | 列出短线兑现的密度、两个卷内高潮的位置与开篇三章的第一个爽点 |
| 生态位垄断 | 把故事放进一个被垄断的生态位：谁垄断什么、主角撬动哪一环、新平衡由谁付账；只换皮不换生态位不算 | 写清垄断者、被撬动的环节，以及主角介入后的新秩序 |
| 数据面板 | 把成长做成可核对的数字（属性、等级、任务、贡献、排行榜），让读者随时看见进步了多少；数字要有人认账，随便写的等级不算 | 写清面板上会出现哪几项、每项怎么变，以及谁承认这张榜（排名对资源分配有什么实际后果） |
| 记忆点标签 | 给世界与主角造几个一眼能记住、能被读者复述的标签（称号、流派、道具、口号），名字要能搜索、能出现在章末钩里 | 写出三个可传播的标签，说明它们第一次出现在哪一幕、由谁说出 |
| 长线续航 | 设定必须撑住长篇：敌人、地图、资源与等级都留了继续加层的位置，不靠临时改设定续命；三十章就把牌打光不算 | 写出第二卷与终局各新增什么层级，并说明它与你现在写的规则同源 |

### v3 重写说明

旧表是通用文学构思法（混搭、倒置、绑定、闭环……）。实机换组时作者反复给出「格局太小」「不够网文」的意见，说明缺的不是文学巧思，而是**网文设定该有的实做**：优势要被世界持续供料、台阶要看得见、对手随地图升格、硬通货要有人分配、留够加层空间。所以 v3 把清单换成 12 条网文设定生成法，每条都带"必须产出什么"；旧表背后的通用创作纪律没有丢，收在下面的「创意推演原则（自检）」里。

### 网文设定的六条硬检查

一条设定能不能用，按这六条过一遍（自检口径，不是引擎门槛）：

| 检查 | 问自己 |
|---|---|
| 可量化 | 数值、等级、资源能不能写出具体数字，读者能不能看见涨了多少 |
| 可升级 | 有没有明确的下一级、升级条件与代价，读者能不能回答"下一步要什么" |
| 可冲突 | 有没有人在抢、谁分配、抢的后果是什么；没有争夺的设定只是背景 |
| 可记账 | 能不能进资源账（有来源、有稀缺点、有持有者），而不是散文里的形容词 |
| 可扩展 | 能不能撑到百万字：敌人、地图、资源、等级都留了继续加层的位置 |
| 开篇三章用得上 | 开篇三章的第一场冲突里能不能真的用上它，而不是等到第二卷才兑现 |

换组时保留否决理由（`regroup` 会记录原话），并按 round 顺延到下一个方法；不要用同一方法反复换皮。

### 与已选方向的边界

- 方法只在已选方向内改变推进方式与代价结构。opening/2 的世界门为第四门；已选 `allow_special_mechanism: false` 时不能引入特殊能力，已选禁区同样生效。
- 视角门为第二门，自己的 `scene` 用该方案的人称展示效果；后续方案沿用已选视角。第一门题材样本发生在视角选择前，不据此替作者锁定视角。
- 世界门先于主角、关系与终局门；后续欲望、限制和选择须能在所选世界中成立，终局承接读者承诺。无特殊机制时从现实条件、制度或关系寻找压力，不强造超自然代价。
- 方法与选项的 `value` 字段是两回事：方法体现在 `driver`（这一版如何推进）与 `tradeoff`（这一版的代价），不写进 `value` 的结构字段里——`value` 会被逐字保留进最终约定。
- 结构门（体量与分卷）没有创意方案：档位由引擎按 `contracts.SCALE_TIERS` 即时给出，主干展示，不派 Worker 或提交方案回执；方法不适用于该门。

## 卷级转折方法

方法清单在 `contracts.VOLUME_TURNS`，用于卷纲与章纲。按本卷职责和题材选择方法，检查变化是否提前产生后果，不强制每卷使用全部方法或在精确半程翻盘。

| 方法 | 做法 |
|---|---|
| 卷中转折 | 在卷半程安排关键翻盘，改变后半卷的对抗走向 |
| 代价递进 | 卷内分段支付不可替代之物（名誉、靠山、同伴），换取核心真相 |
| 对手揭露 | 前期明面阻力实为棋子，真正的对手在中期浮出水面 |
| 线索回收 | 前期的闲笔或次要人物在卷尾成为决定胜负的关键手 |
| 双线演进 | 核心对手在幕后推进自己的目标，与主角线交错施压 |

设计节点用 `id/kind/purpose/ending_condition/required/window` 表达职责与收束条件，跨卷线路用 `continues: true`；节点与章号窗口规则见 [叙事推进](narrative.md#卷纲)。回收线索前核对原文和已成立证据，不临时补造过去。**伏笔是承诺，要进账**：在卷纲 `hooks` 里登记窗口与 `required`/`continues`，章纲用 `plant`/`payoff` 两个动作执行；`hook_refs` 只用于中途承接已经埋下的承诺，不新增动作。规则见 [伏笔账](narrative.md#伏笔账卷纲声明章纲执行)。

## 创意推演原则（自检）

- **差异化与商业卖点**：在经典框架里找微创新切入点（新生态位、反套路冲突、新奇职业），不照搬类型套路，也不为不同而不同。
- **世界守恒**：任何非常规能力或机制必须有来源、上限与代价；没有特殊机制的项目也遵守其物理、社会与信息边界。
- **生态位与动机自洽**：利益驱动一切，没有纯粹工具人；人物行为扎根于认知视界与处境，不为推剧情降智。
- **主线贯穿**：开书就确立贯穿全书的明确主线与因果链，各卷挂载其上——读者任何阶段都清楚主角在为主线的哪一步而战。
- **闭环收敛**：脑暴不以聊天为目的，每次推演收敛为可签发的方案或条目。

## 名字与称呼

主角名在主角门确定，后续人物在章纲 `new_entities` 里补充档案；当前字面限制见任务 `policy`，修改入口见 [运行](runtime.md)。可以先用职位、特征或外号出场，新身份及关系按章纲声明、由正文与投影状态落地；不能覆盖既有称呼或把候选经历冒充已成立历史。关系门决定核心张力，推进门承接主要对抗；书名在最后选定，与承诺、终局和文风相称。
