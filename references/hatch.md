# 创意工具箱

何时读：开书逐门选择要换组、方案同质化，或卷规划需要中期转折时。

## 使用边界

本页提供构思方法，方案格式和门序见 [逐门开书](opening.md)，文学判断见 [创作与写审](craft.md)。已选方向和任务交付要求是约束；具体方法只用于当前构思，不变成所有章节通用的情节门槛。

透镜用于**把下一个方案推离已有方案**，只用来想，不写进作者可见方案。同一门换组后，应能指出推进方式与代价的实际差别，不能只换措辞或附上方法自评。

## 八个设定生成方法

方法清单在 `contracts.LENSES`，当轮方法以任务简报中的 `lens_brief` 为准；下表用于理解和自检。采用某方法时检查其作用，不要求八种方法全部出现，也不要求每次选择都支付不可逆代价。

| 透镜 | 要点 | 采用该方法时检查 |
|---|---|---|
| 混搭 | 两种差异化设定深度参与因果，双方都改变故事走向 | 先写清两个设定各自成立，再指出互相牵制的具体后果 |
| 倒置 | 颠覆类型固有假定，并在终局回溯闭环 | 先写清被倒置的公理，再给出终局如何回到它 |
| 代价 | 突破必须支付不可逆的实质代价，代价改变后续抉择 | 写清代价的具体形态，以及它如何限制下一次选择 |
| 限制 | 严苛限制驱动破局策略，主角靠判断取胜 | 写清限制的边界与破局要用的具体手段 |
| 认知差 | 信息差制造不可逆选择，知道本身带来风险 | 写清谁知道什么、这层差如何逼出选择 |
| 规则推演 | 一条底层规则推到社会结构与经济秩序的极限 | 写清规则边界，以及它挤压出的制度、代价与冲突 |
| 绑定 | 主角与核心对手在物理或命运上深度绑定 | 写清绑定机制，以及双方各自被限制的动作 |
| 闭环 | 终局与初始预期形成有据可依的反转 | 写清初始预期、终局事实与中间需要埋设的线索 |

换组时保留否决理由（`regroup` 会记录原话），并按 round 顺延到下一个透镜；不要用同一方法反复换皮。

### 与已选方向的边界

- 透镜只在已选方向内改变推进方式与代价结构。opening/2 的世界门为第四门；已选 `allow_special_mechanism: false` 时不能引入特殊能力，已选禁区同样生效。
- 视角门为第二门，自己的 `scene` 用该方案的人称展示效果；后续方案沿用已选视角。第一门题材样本发生在视角选择前，不据此替作者锁定视角。
- 世界门先于主角、关系与终局门；后续欲望、限制和选择须能在所选世界中成立，终局承接读者承诺。无特殊机制时从现实条件、制度或关系寻找压力，不强造超自然代价。
- 方法与选项的 `value` 字段是两回事：方法体现在 `driver`（这一版如何推进）与 `tradeoff`（这一版的代价），不写进 `value` 的结构字段里——`value` 会被逐字保留进最终约定。
- 结构门（体量与分卷）没有创意方案：档位由引擎按 `contracts.SCALE_TIERS` 即时给出，主干展示，不派 Worker 或提交方案回执；透镜不适用于该门。

## 卷级转折方法

方法清单在 `contracts.VOLUME_TURNS`，用于卷规划（`volume_plan`）与后续章计划。按本卷职责和题材选择方法，检查变化是否提前产生后果，不强制每卷使用全部方法或在精确半程翻盘。

| 方法 | 做法 |
|---|---|
| 卷中转折 | 在卷半程安排关键翻盘，改变后半卷的对抗走向 |
| 代价递进 | 卷内分段支付不可替代之物（名誉、靠山、同伴），换取核心真相 |
| 对手揭露 | 前期明面阻力实为棋子，真正的对手在中期浮出水面 |
| 线索回收 | 前期的闲笔或次要人物在卷尾成为决定胜负的关键手 |
| 双线演进 | 核心对手在幕后推进自己的目标，与主角线交错施压 |

设计节点用 `cause/choice/cost/outcome/disclosure` 表达转折，依赖存在且无环；节点和章号窗口规则见 [叙事推进](narrative.md)。回收线索前核对原文和已成立证据，不临时补造过去。普通线索不必全部登记为 hook；已登记承诺按其状态、期限和延期上限处理。

## 名字与称呼

主角名在主角门确定，后续人物按计划与档案补充；当前字面限制见任务 `policy`，修改入口见 [运行](runtime.md)。可以先用职位、特征或外号出场，新身份及关系由独立审稿依据正文登记；不能覆盖既有称呼或把候选经历冒充已成立历史。关系门决定核心张力，推进门承接主要对抗；书名在最后选定，与承诺、终局和文风相称。
