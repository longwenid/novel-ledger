# 创意工具箱

何时读：开书逐门选择要换组、方案同质化，或卷规划需要中期转折时。

透镜不是标签，是**把下一个方案推离已有方案的方法**。同一门连续给出措辞不同而结构相同的方案，等于没有方案；判据是：读者能否说出这一版与前几版在推进方式上的具体差别。

## 八个设定生成方法

权威清单在 `contracts.LENSES`，任务 payload 的 `lens_brief` 会带上本轮方法全文；下表用于理解方法与自检。

| 透镜 | 要点 | 落地要求 |
|---|---|---|
| 混搭 | 两种差异化设定深度参与因果，双方都改变故事走向 | 先写清两个设定各自成立，再指出互相牵制的具体后果 |
| 倒置 | 颠覆类型固有假定，并在终局回溯闭环 | 先写清被倒置的公理，再给出终局如何回到它 |
| 代价 | 突破必须支付不可逆的实质代价，代价改变后续抉择 | 写清代价的具体形态，以及它如何限制下一次选择 |
| 限制 | 严苛限制驱动破局策略，主角靠判断取胜 | 写清限制的边界与破局要用的具体手段 |
| 认知差 | 信息差制造不可逆选择，知道本身带来风险 | 写清谁知道什么、这层差如何逼出选择 |
| 规则推演 | 一条底层规则推到社会结构与经济秩序的极限 | 写清规则边界，以及它挤压出的制度、代价与冲突 |
| 绑定 | 主角与核心对手在物理或命运上深度绑定 | 写清绑定机制，以及双方各自被限制的动作 |
| 闭环 | 终局与初始预期形成有据可依的反转 | 写清初始预期、终局事实与中间需要埋设的线索 |

换组时保留否决理由（`regroup` 会记录原话），并按 round 顺延到下一个透镜；不要用同一方法反复换皮。

### 与已选方向的边界

- 透镜只改变**推进方式与代价结构**，不推翻已选无外挂、生活流、禁机制等约束。世界门已选 `allow_special_mechanism: false` 时，任何透镜都不能引入特殊能力。
- 主角门、世界门与终局门的方法要能互相验证：世界门选的机制必须解释主角门所选欲望与底线的代价来源；终局门的闭环要能回溯到题材门承诺的读者体验。
- 方法与选项的 `value` 字段是两回事：方法体现在 `driver`（这一版如何推进）与 `tradeoff`（这一版的代价），不写进 `value` 的结构字段里——`value` 会被逐字保留进最终约定。

## 卷级转折方法

权威清单在 `contracts.VOLUME_TURNS`，用于卷规划（`volume_plan`）与后续章计划：把转折安排在卷中而不是堆在卷尾。

| 方法 | 做法 |
|---|---|
| 卷中转折 | 在卷半程安排关键翻盘，改变后半卷的对抗走向 |
| 代价递进 | 卷内分段支付不可替代之物（名誉、靠山、同伴），换取核心真相 |
| 对手揭露 | 前期明面阻力实为棋子，真正的对手在中期浮出水面 |
| 线索回收 | 前期的闲笔或次要人物在卷尾成为决定胜负的关键手 |
| 双线演进 | 核心对手在幕后推进自己的目标，与主角线交错施压 |

设计节点用 `cause/choice/cost/outcome/disclosure` 表达这些转折；节点因果必须无环且依赖存在，所以转折不能只写意图，要落到具体节点与章号区间。承诺（hook）的延期有上限，用「线索回收」时先确认该线索已登记为承诺或已作为历史断言成立，不要靠临时补造事实回收。

## 名字与称呼

人物起名在主角门与人物档案阶段完成；名字受项目字面约定约束（默认称呼不含「砚」，改规则用 `lexical` 命令）。允许先用职位、特征或外号出场，再由独立事实审稿者按正文登记正式身份——不要在执笔正文里凭空宣布新身份的既有关系，那是事实结算的职责。
