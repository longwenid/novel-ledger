# 创意工具箱

何时读：开书构思、换组、方案同质化，或卷纲需要转折时。

## 使用边界

门序与格式见 [逐门开书](opening.md)，正文写作见 [创作与自比](craft.md)。本页统一维护开书创意、换组与转折方法，任务中的方法标签只供定位与轮换。方法用来想，不写进作者可见方案，不新增作者必答门或独立校验任务。

默认面向起点/番茄男频长篇；作者原话与已选方向优先。短篇、现实题材、慢热、非数值成长和不同文风均可成立，展开尺度由题材和体量决定，不固定打脸频率或每卷换敌。

## 先想一本让人想追的书

默认目标是起点、番茄的商业网文体验：读者能快速理解主角面对什么、有什么值得期待的机会，以及接下来想看他做成什么。起点与番茄都有多种风格，不能把某个榜单、书名长度、系统流或快节奏当作平台的统一规则。作者指定平台、题材、受众或节奏时优先遵守；未指定平台时以清晰卖点和连载续航为共同目标，不假称某一案必火。

生成每组前，在内部先构思多于最终展示数量的候选，再留下最有吸引力且彼此真不同的 2～3 个；不向作者展示内部草稿、评分或淘汰过程，也不添加新的作者必答门。先想故事再填字段：

1. **读者想看什么**：先确定可体验的回报，如逆转不利处境、展示稀缺本领、攻略对手、探知真相、创造基业或人物间的牵绊。不是把这些词贴在选项上，而是让读者想知道下一步会怎样。回报依题材和作者要求而定，不强制复仇、打脸或升级。
2. **为什么想点开**：用人物的处境和一个具体机会、反差或难题构成可以复述的卖点；找出熟悉题材中属于这一案的独特兑现方式。单靠「身世不凡」「隐藏真相」「一步步变强」、罕见名称或规则复杂度撑不起钩子。新奇要能看懂、接上人物行动，不靠突然堆设定。
3. **为什么偏偏是这个主角**：想出当下目标、阻力和可以利用的独特条件，以及他要主动采取的行动。前门未定身份或能力时只作画面试想，不当作已选设定，也不挤占后门决定；已选限制不可被试想绕开。
4. **第一波看点**：想一个开篇能看见的困境或机会、主角的选择，以及可期待的首个结果。展示他怎样争取，而不只写「得到机会」；回报可以是小胜、关系变化或线索，不许只承诺宏大未来。不得替作者固定章数或承诺无条件成功。
5. **为什么还能继续看**：试推两次性质不同的后续行动：先前行动如何改变处境，另一个人物或对手又怎样回应？回报与代价应改变下一次选择，不能只是增加订单、换更强敌人或重复同一任务。短篇按篇幅缩小，不硬造长线。

### 提交前比较候选

在内部逐案回答：读者这次等着看什么；主角凭什么能介入、怎样行动；谁会阻拦或回应；开篇可感知什么结果；后续故事如何继续。把答案横向比较，不用固定标签凑数量，也不向作者展示检查表。

- **交换测试**：把两案的职业、地点、器物和能力名称互换后，如果人物仍做同样的事、面对同类阻力、得到同种回报，说明只是换皮；保留较强的一案，把另一案重想为不同的目标、行动路径或对抗。两案都是经营、探案或修炼并不自动同质；关键是读者追看的过程与结果是否不同。
- **具体兑现测试**：遮住题材标签与修饰词，能否从 `pitch`、`scene` 和 `driver` 看出谁要做什么、最有意思的障碍或机会是什么、胜负会带来什么？不能就补具体情境、动作和结果，不靠「热血爽快」「暗流涌动」代替。
- **因果与可选性测试**：机会如何成立、对手为何行动、所说代价和收益能否接上场面？本门不同方案要提供作者能看见的取舍，而非仅有难度、规模或形容词的差异。语义靠设计者判断，机械通过只表示格式合格。

换组时从作者拒绝的点重新发散，不围绕上一组换词续写；不可借机推翻已选方向。作者明确限定单一体验时，在这个范围内改变实现路径，不能为追求差异强加其不想要的设定。

只把与本门有关的决定写进 `value`；用 `pitch` 让人一眼理解这一案的吸引力，`scene` 展示人物行动与可感知的后果，`driver` 说明后续怎么推进，`tradeoff` 说明真正取舍，`fit_reason` 指向作者已选内容。画面可以是试想，不应暗中确定尚未选择的主角姓名、职业、视角或机制；作者不选该案，试想不进入已选事实。

### 十三门各自怎样增加吸引力

| 门 | 除字段完整外，着重比较什么 |
|---|---|
| 题材与阅读承诺 | 同一题材下读者追的是哪种体验：例如破局、经营、冒险；说明不同体验如何呈现在故事里，不只罗列类型标签。 |
| 核心设想 | 用可复述的处境或变化连接人物机会、阻力和读者期待；世界命题要能引出故事，不能只有抽象宏大叙述。 |
| 体量与分卷 | 引擎展示现有档位；结合作者意图解释篇幅取舍，不虚构新档或故事。 |
| 世界架构 | 不只比地图和史诗背景：比较世界规则如何制造机会与对抗，让普通人的生活和主角未来行动都能体现区别。 |
| 格局路径 | 比较前期怎样参与、中期怎样改变对抗、后期为什么还有新选择；扩大舞台不是唯一升级。 |
| 写作视角 | 用同一事件试读不同跟随对象与知情范围，让作者看见代入、悬念或多线的差别。 |
| 主角来历 | 来历要改变他的处境、信息差或人际风险；不只比较穿越方式的名称。 |
| 核心优势 | 比较优势在机制层占住哪个环节（见「金手指类型与供料」），有可想象的首次使用、后续变化和限制；没有金手指也可来自技艺、关系或判断。 |
| 主角处境 | 不只填身份欲望底线：展示他为什么现在必须行动，以及选择会伤到什么。 |
| 多方对抗 | 给对手自己的目标与可执行动作，比较主角怎样应对以及获胜后的新局面。 |
| 人物关系 | 让不同关系既能带来帮助，也有独立选择和利益；不把人物当夸赞主角的工具。 |
| 阶段兑现 | 说清读者早期期待看到什么、主角如何争取，和后续阶段有何新回报；具体期限遵循本门现有协议。 |
| 书名 | 结合已选卖点给清晰直给、意象或反差等不同方向；按作者偏好选择，不保证流量或套用固定句式。 |

## 设定生成方法

常规扎实与因果脑洞是同等有效的路线。常规从熟悉规则下的具体处境、利益、关系和兑现入手；脑洞从一处可说清的变化入手，推演代价与后果，变化可以发生在现实制度、信息或人物关系上，也可以是幻想规则。两条路线都要让读者看得懂眼前的生活与行动。

作者未限定时，在适合比较故事构思的门里可从常规扎实、因果脑洞、人物关系或推进方式等不同入口发散，再按本书的读者体验选择 2～3 案；不用规定某个入口必占一席。作者明确只要正常、脑洞或无超自然时服从，不硬塞另一条路线。视角、命名等门仍围绕本门决定比较。

下面的方法按当前门与作者要求选用，不是必做清单；题材、视角、命名等门只解决本门决定，结构门由引擎给档位。

| 方法 | 用法 |
|---|---|
| 主流正统 | 沿熟悉框架深挖具体处境、关系和兑现，让人物的选择与执行形成差异。 |
| 金手指倒推 | 从既定世界寻找可反复运用的优势，追问条件、供给与竞争；普通技能也能成为优势，机制分型见「金手指类型与供料」。 |
| 等级闭环 | 需要明确进阶时，让条件、所得与门槛相连；谁承认进阶、权利如何变化，比级数更有用。 |
| 对手换图 | 需要拓展舞台时，从眼前对手追到关系网络与规则制定者，保留旧冲突造成的后果。 |
| 硬通货 | 从稀缺的金钱、时间、资源或信用追问分配与依赖，找到人物不得不行动的压力。 |
| 身份马甲 | 需要多重身份时，利用不同关系中的信息差，推演维持身份与暴露的代价。 |
| 套路反打 | 沿读者熟悉的期待改变选择、代价或结果，先让原有规则成立，再形成意外。 |
| 代价上限 | 用已成立的限制影响下一次选择，让付出产生后果，避免临时削弱或增强能力。 |
| 爽点倒推 | 从作者要的情绪回报倒推行动与铺垫，按题材安排兑现，不预定高潮数量与间隔。 |
| 生态位垄断 | 找到被占据的机会或渠道，推演撬动它会帮到谁、伤及谁以及新的分配难题。 |
| 数据面板 | 已选数字化成长时，让数值变化对应实际能力、资格或资源，明确谁承认这些数字。 |
| 记忆点标签 | 从有作用的物件、称呼或习惯提炼记忆点，让读者先在行动中认识它。 |
| 长线续航 | 让眼前解决办法产生后续选择，旧关系与承诺继续有用，按篇幅留出展开空间。 |
| 世界暗面 | 追问眼前困境背后的自然压力、制度失灵或人为伤害，找出获利者与承担者。 |
| 纪元断层 | 从旧时代留下的制度、物件或关系追到今天的便利与负担，揭示被遗忘的选择。 |
| 规则博弈 | 推演人物怎样遵守、利用或挑战规则，以及他人如何回应；改写规则要付出代价。 |
| 非数值成长 | 让认知、关系、责任或心性变化改变实际选择，即使能力和地位未变也能前进。 |
| 表层锚点 | 用一件物、一次行动或一段关系承载眼前相关的设定，其余背景按需要揭示。 |

### 金手指类型与供料

金手指按「在世界的哪个环节占便宜」区分，不按名词区分。同一个「系统」可以分别是发放资格的授权、可重来的试错或兑换资源的转换，落点不同故事就不同；两个不同名词若在故事里做同一件事，照交换测试判为换皮。系统、面板、签到、模拟器等常见名词都能在表里找到机制落点。此表只用于构思与自审，不写成给作者看的分类标签；作者已定机制时沿用并推演后果，不为差异推翻。

| 类型 | 靠什么占便宜 | 不答住就只是标签 |
|---|---|---|
| 先知 | 知道别人不知道的：重生记忆、鉴定、读心、勘察 | 信息为何可能失真、过期或被误读；旁人怎样验证与怀疑他 |
| 试错 | 可承受的重来：存档、模拟、回溯、预演 | 试错的次数与留存代价；世界的危险是否可推理，否则模拟只是通关攻略 |
| 加速 | 时间差：修炼加速、熟练继承、流速差 | 与同侪的错位谁先察觉，来源如何解释而不惊动规则 |
| 转换 | 兑换与合成：万物兑换、点石成金、升格 | 兑换率由谁定，产出冲击谁的市场、组织与分配 |
| 垄断 | 独占渠道：独家货源、唯一产线、专营 | 渠道依赖谁、何时被掐断，模仿者从哪出现 |
| 授权 | 发放资格与权限：名额、任务、准入 | 授权者是谁、为何给他，条款何时反噬 |
| 复用 | 吸收与回收：遗物提取、能力继承、掉落 | 复用是否需要到场或同意，被复用者与遗属如何反应 |
| 判定 | 规则解释权：仲裁、审计、豁免 | 判定为何服众，上诉与钻空者从哪来 |

供料三问接世界门：资源从哪来（resource 的 source 与 allocator）、谁因此争夺（factions 与贯穿矛盾）、等级怎么排（tiers）。只在主角身上生效、不改变世界分配与依赖的，是标签不是机制。

优势门五键承接：每案答得出优势本身、来源、成长条件、代价与上限，任一键靠名词带过就退回了标签。无金手指的案件不因无外挂免检——技艺、关系、判断同样要说清在哪个环节占便宜。

### 从处境或变化推演后果

常规路线先抓具体难题，脑洞路线先抓关键变化，再按本门需要追问后果。下面是可选的思考角度，不必逐项答满，也不要求每个故事都有文明危机：

- **生活与关系**：谁会得到或失去什么，亲近的人为什么也可能反对，第一场行动如何看见这些压力？
- **制度与历史**：过去的选择怎样留下今天的便利与负担，谁依赖它，改变它会伤及谁？
- **后续与终局**：眼前问题解决后会出现什么新责任，哪些选择仍不能由能力或地位代替？

世界门的五项架构共同解释一个世界：历史造成今天的分布与依赖，各方对贯穿矛盾有不同回应，终极谜题会改变行动理由。格局连接阶段与终局，可以发生在同一空间；世界全貌供作者规划，开篇只呈现眼前相关的行动与后果。

### 与已选方向的边界

世界、格局与视角先定，主角来历与优势再接入；身份尚未选定时用“主角”指代，不提前锁定姓名、职业。视角门之前的画面不锁人称；选定后沿用其人称和允许的换人范围。已选无特殊机制就从现实条件和制度中找动力。短篇可展开一段文明历史的切面，宏大不强制等于星海诸天。

已选记录由后门完整读取。方法体现在 `driver` 与 `tradeoff` 的实际故事差异里，不把方法名塞入 `value`。若作者要求推翻已选世界，返回对应门再选。记录结构和逐字传递由引擎检查，创意质量与因果合理性由当前设计者在原任务内判断。

### 写作视角

这一门决定读者通过哪些人物、在什么知情范围内读故事，不同时选冷硬／幽默、短句／长句等文风。作者已有主角中心、双主角或群像要求时直接承接，只补实际缺口。

选项标题使用网文常见称呼，下面是可选方向，不是互斥类型或固定菜单：

| 常见写法 | 这本书怎样讲 | 主要取舍 |
|---|---|---|
| 主角视角 | 以一位主角的经历为中心；可固定跟随，也可允许少量关键配角场景，选案时说清 | 代入与主线集中；远处行动通常随主角接触后展开 |
| 双主角视角 | 两位核心人物各有目标和行动，按场景或章节切换，彼此的选择改变对方处境 | 能呈现两方关系与信息差；切换要让读者认清当前跟随者 |
| 群像视角 | 多位核心人物各有目标、选择与后果，共同推动事件；分场跟随不同人物，不只围绕单一主角插入配角 | 能展开多方利益与独立行动线；须维持可辨识的人物目标和线路承接，不要求戏份平均 |
| 旁观者视角 | 跟随见证者观察核心人物或事件，只写其亲历、获知或带来源的推测 | 保留核心人物的距离与未知；见证者不能替别人知道心事 |
| 全知视角 | 叙述者可跨人物、地点和时间说明情况，明确哪些真相仍按章纲暂不揭示 | 便于展示全局和戏剧反讽；叙述者可知不等于角色已知，也不等于一次把真相讲完 |

人物组织、人称与知情范围可以组合，例如“第三人称群像，分场限知”或“以主角为中心的全知叙述”。用“我”还是“他／她”、能看谁的内心、何时切换都在同一候选里说明，不拆成新门。作者已定人称或群像方向时，同组只比较其范围内有实际差别的方案；未定时按本书需求给 2～3 案，不把主角视角作为所有题材的唯一默认，也不因世界宏大就强制群像。

各案用同一件事的对应片段试读，事实、人物处境与大致语感保持一致，只改变叙述位置和信息范围；仍按通用方案协议交 2～3 条 scene，不另交完整试章。取舍写贴近人物、保留悬念或展示远处行动之间的实际得失，不把不同文风伪装成视角差异。未定人物姓名时用“主角”等称呼。

作者只需选一个方案。执行者将其整理进既有 pov、voice、style_traits：分别保存人称与跟随范围、白话讲述说明、知情与换人的补充约定，不增加字段或追问；文风档案的选择和切换另见 [文风](style.md)。旧选择中已有的表达偏好继续保留，不据此追改历史约定。

群像选择还须由后续人物与关系设计、卷纲和章纲承接独立目标及行动后果；仅轮流写几个人的内心不能代替群像设计。具体承接见 [人物与场景](craft.md#人物与场景)。

### 换组

从 `opening_rejections` 和作者新偏好判断被拒的是处境、关系还是推进方式，再改变相应内容；只换名字、形容词或收益说法不算新方向。方法轮换服从作者要求，不能借换组推翻已选决定。作者说格局太小，可以重推影响范围与长期选择，无需不断加怪或放大地名。

## 卷级转折方法

用于卷纲与章纲，按本卷职责和题材选择，检查变化是否有前因并产生后果，不强制每卷用全或在精确半程翻盘。

| 方法 | 做法 |
|---|---|
| 卷中转折 | 在卷中合适处安排变化，改变后续对抗走向 |
| 代价递进 | 前一次选择的付出影响下一次抉择，所得可以是真相、关系或行动空间 |
| 对手揭露 | 新证据改变对阻力来源或对方目的的理解，不必另设幕后黑手 |
| 线索回收 | 已出现的细节或人物在合适处发挥作用，让结果接得上此前证据 |
| 双线演进 | 另一方独立推进自己的目标，两条行动线相互影响 |

设计节点用 `id/kind/purpose/ending_condition/required/window` 表达职责与收束条件，跨卷线路用 `continues: true`；节点与章号窗口规则见 [叙事推进](narrative.md#卷纲)。回收线索前核对原文和已成立证据，不临时补造过去。**伏笔是承诺，要进账**：在卷纲 `hooks` 里登记窗口与 `required`/`continues`，章纲用 `plant`/`payoff` 两个动作执行；`hook_refs` 只用于中途承接已经埋下的承诺，不新增动作。规则见 [伏笔账](narrative.md#伏笔账卷纲声明章纲执行)。

## 创意推演原则（自检）

- **故事吸引力**：比较眼前处境、关系张力与兑现方式；熟悉框架可以直接成立，特殊设定需产生具体后果。
- **世界守恒**：任何非常规能力或机制必须有来源、上限与代价；没有特殊机制的项目也遵守其物理、社会与信息边界。
- **动机自洽**：利益、感情、责任、尊严与误判都可能驱动选择；从人物当时的认知和处境判断，保留配角自己的需要。
- **因果承接**：后续变化能接上此前选择及后果；静章、支线和暂时看不清目的都可以有作用。
- **形成选择**：把本门真正不同的方向写成可比较方案，由作者决定，不另加评分或必答问题。

## 名字与称呼

姓名贴合世界与阶层，可从常见字、双字名和日常称呼入手，避免反复套用“潇洒姓＋玄乎单字”。连同全名、日常称呼、外号或职衔一起试读，听清不同关系中的人会怎样叫他。

主角名在主角门确定，后续人物在章纲 `new_entities` 里补充档案；当前字面限制见任务 `policy`，修改入口见 [运行](runtime.md)。可以先用职位、特征或外号出场，新身份及关系按章纲声明、由正文与投影状态落地；不能覆盖既有称呼或把候选经历冒充已成立历史。对手门先定对抗网络，关系门的助力与背叛依附其上；书名在最后选定，与承诺、终局和文风相称。
