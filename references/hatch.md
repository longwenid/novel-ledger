# 创意工具箱

何时读：开书构思、换组、方案同质化，或卷纲需要转折时。

## 使用边界

门序与格式见 [逐门开书](opening.md)，正文写作见 [创作与自比](craft.md)。本页统一维护开书创意、换组与转折方法，任务中的方法标签只供定位与轮换。方法用来想，不写进作者可见方案，不新增作者必答门或独立校验任务。

默认面向起点/番茄男频长篇；作者原话与已选方向优先。短篇、现实题材、慢热、非数值成长和不同文风均可成立，展开尺度由题材和体量决定，不固定打脸频率或每卷换敌。

## 设定生成方法

常规扎实与因果脑洞是同等有效的路线。常规从熟悉规则下的具体处境、利益、关系和兑现入手；脑洞从一处可说清的变化入手，推演代价与后果，变化可以发生在现实制度、信息或人物关系上，也可以是幻想规则。两条路线都要让读者看得懂眼前的生活与行动。

作者未限定时，在适合比较故事构思的门里用 2～3 案展示常规扎实与因果脑洞的不同入口；第三案可以改变关系或推进方式，无需比前两案更怪。作者明确只要正常、脑洞或无超自然时服从，不硬塞另一条路线，也不要求每门各占一案。视角、命名等门仍围绕本门决定比较。

下面的方法按当前门与作者要求选用，不是必做清单；题材、视角、命名等门只解决本门决定，结构门由引擎给档位。

| 方法 | 用法 |
|---|---|
| 主流正统 | 沿熟悉框架深挖具体处境、关系和兑现，让人物的选择与执行形成差异。 |
| 金手指倒推 | 从既定世界寻找可反复运用的优势，追问条件、供给与竞争；普通技能也能成为优势。 |
| 等级闭环 | 需要明确进阶时，让条件、所得与门槛相连；谁承认进阶、权利如何变化，比级数更有用。 |
| 对手换图 | 需要拓展舞台时，从眼前对手追到关系网络与规则制定者，保留旧冲突造成的后果。 |
| 硬通货 | 从稀缺的金钱、时间、资源或信用追问分配与依赖，找到人物不得不行动的压力。 |
| 身份马甲 | 需要多重身份时，利用不同关系中的信息差，推演维持身份与暴露的代价。 |
| 套路反打 | 沿读者熟悉的期待改变选择、代价或结果，先让原有规则成立，再形成意外。 |
| 代价上限 | 用已成立的限制影响下一次选择，让付出产生后果，避免临时削弱或增强能力。 |
| 爽点倒推 | 从作者要的情绪回报倒推行动与铺垫，按题材安排兑现，不预定高潮数量与间隔。 |
| 生态位垄断 | 找到被占据的机会或渠道，推演撬动它会帮到谁、伤及谁以及新的分配难题。 |
| 数据面板 | 已选数字化成长时，让数值变化对应实际能力、资格或资源，明确谁承认这些数字。 |
| 记忆点标签 | 从有作用的物件、称呼或习惯提炼记忆点，让读者先在行动中认识它。 |
| 长线续航 | 让眼前解决办法产生后续选择，旧关系与承诺继续有用，按篇幅留出展开空间。 |
| 世界暗面 | 追问眼前困境背后的自然压力、制度失灵或人为伤害，找出获利者与承担者。 |
| 纪元断层 | 从旧时代留下的制度、物件或关系追到今天的便利与负担，揭示被遗忘的选择。 |
| 规则博弈 | 推演人物怎样遵守、利用或挑战规则，以及他人如何回应；改写规则要付出代价。 |
| 非数值成长 | 让认知、关系、责任或心性变化改变实际选择，即使能力和地位未变也能前进。 |
| 表层锚点 | 用一件物、一次行动或一段关系承载眼前相关的设定，其余背景按需要揭示。 |

### 从处境或变化推演后果

常规路线先抓具体难题，脑洞路线先抓关键变化，再按本门需要追问后果。下面是可选的思考角度，不必逐项答满，也不要求每个故事都有文明危机：

- **生活与关系**：谁会得到或失去什么，亲近的人为什么也可能反对，第一场行动如何看见这些压力？
- **制度与历史**：过去的选择怎样留下今天的便利与负担，谁依赖它，改变它会伤及谁？
- **后续与终局**：眼前问题解决后会出现什么新责任，哪些选择仍不能由能力或地位代替？

下面是原创种子，只演示两条路线，不规定默认题材或固定剧情：

| 题材 | 常规扎实 | 因果脑洞 |
|---|---|---|
| 现实生活 | 老楼赶在雨季前修缮，预算只够先修屋顶或水管；不同楼层各有损失，旧人情影响表决，答应让步的人也要面对家人的埋怨。 | 老楼试行互评：每户只能为别家的维修需求投票。住户得把别人的困难讲明，旧人情成了交换筹码，最会掩饰窘迫的一家反而排在最后。 |
| 幻想冒险 | 两座山门共用药谷，冬季减产让旧配额难以维持；守约可能让病人断药，抢收又会毁掉来年的生计。 | 药草只在无人认领的土地生长。放弃领地能救急，却会失去给门下人的收入承诺与防线；偷偷占地又使药草枯死，分药时的争执牵出长期选择。 |

世界门的五项架构共同解释一个世界：历史造成今天的分布与依赖，各方对贯穿矛盾有不同回应，终极谜题会改变行动理由。格局连接阶段与终局，可以发生在同一空间；世界全貌供作者规划，开篇只呈现眼前相关的行动与后果。

### 与已选方向的边界

世界、格局与视角先定，主角来历与优势再接入；身份尚未选定时用“主角”指代，不提前锁定姓名、职业。视角门落在世界与格局之后：此前各门（脑洞、世界、格局）的画面不锁人称，视角门的每案画面使用该案候选人称，让作者直接比较读感；视角确定后的画面沿用其人称。已选无特殊机制就从现实条件和制度中找动力。短篇可展开一段文明历史的切面，宏大不强制等于星海诸天。

已选记录由后门完整读取。方法体现在 `driver` 与 `tradeoff` 的实际故事差异里，不把方法名塞入 `value`。若作者要求推翻已选世界，返回对应门再选。记录结构和逐字传递由引擎检查，创意质量与因果合理性由当前设计者在原任务内判断。

### 换组

从 `opening_rejections` 和作者新偏好判断被拒的是处境、关系还是推进方式，再改变相应内容；只换名字、形容词或收益说法不算新方向。方法轮换服从作者要求，不能借换组推翻已选决定。作者说格局太小，可以重推影响范围与长期选择，无需不断加怪或放大地名。

## 卷级转折方法

用于卷纲与章纲，按本卷职责和题材选择，检查变化是否有前因并产生后果，不强制每卷用全或在精确半程翻盘。

| 方法 | 做法 |
|---|---|
| 卷中转折 | 在卷中合适处安排变化，改变后续对抗走向 |
| 代价递进 | 前一次选择的付出影响下一次抉择，所得可以是真相、关系或行动空间 |
| 对手揭露 | 新证据改变对阻力来源或对方目的的理解，不必另设幕后黑手 |
| 线索回收 | 已出现的细节或人物在合适处发挥作用，让结果接得上此前证据 |
| 双线演进 | 另一方独立推进自己的目标，两条行动线相互影响 |

设计节点用 `id/kind/purpose/ending_condition/required/window` 表达职责与收束条件，跨卷线路用 `continues: true`；节点与章号窗口规则见 [叙事推进](narrative.md#卷纲)。回收线索前核对原文和已成立证据，不临时补造过去。**伏笔是承诺，要进账**：在卷纲 `hooks` 里登记窗口与 `required`/`continues`，章纲用 `plant`/`payoff` 两个动作执行；`hook_refs` 只用于中途承接已经埋下的承诺，不新增动作。规则见 [伏笔账](narrative.md#伏笔账卷纲声明章纲执行)。

## 创意推演原则（自检）

- **故事吸引力**：比较眼前处境、关系张力与兑现方式；熟悉框架可以直接成立，特殊设定需产生具体后果。
- **世界守恒**：任何非常规能力或机制必须有来源、上限与代价；没有特殊机制的项目也遵守其物理、社会与信息边界。
- **动机自洽**：利益、感情、责任、尊严与误判都可能驱动选择；从人物当时的认知和处境判断，保留配角自己的需要。
- **因果承接**：后续变化能接上此前选择及后果；静章、支线和暂时看不清目的都可以有作用。
- **形成选择**：把本门真正不同的方向写成可比较方案，由作者决定，不另加评分或必答问题。

## 名字与称呼

姓名贴合世界与阶层，可从常见字、双字名和日常称呼入手，避免反复套用“潇洒姓＋玄乎单字”。连同全名、日常称呼、外号或职衔一起试读，听清不同关系中的人会怎样叫他。

主角名在主角门确定，后续人物在章纲 `new_entities` 里补充档案；当前字面限制见任务 `policy`，修改入口见 [运行](runtime.md)。可以先用职位、特征或外号出场，新身份及关系按章纲声明、由正文与投影状态落地；不能覆盖既有称呼或把候选经历冒充已成立历史。对手门先定对抗网络，关系门的助力与背叛依附其上；书名在最后选定，与承诺、终局和文风相称。
