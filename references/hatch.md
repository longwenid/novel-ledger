# 创意工具箱

何时读：开书构思、换组、方案同质化，或卷纲需要转折时。

## 使用边界

门序与格式见 [逐门开书](opening.md)，创作判断见 [创作与自比](craft.md)。方法用来想，不写进作者可见方案，不新增作者必答门或独立校验任务。作者原话与已选设定优先；不得借换组推翻此前决定。

## 设定生成方法

当前方法库在 `contracts.LENSES`；不在指南复制另一份完整清单。`opening/6` 按门选方法池，换组在池内轮换，当轮以简报 `lens_brief` 为准。

| 门 | 优先方法 | 应推演出什么 |
|---|---|---|
| 脑洞 | 规则博弈、纪元断层、世界暗面、主流正统 | 改变哪条根规则；为何现在失衡；普通人、组织、文明分别受到什么影响 |
| 世界 | 纪元断层、生态位垄断、世界暗面、长线续航、主流正统 | 历史选择造成的空间格局、相互依赖、根本冲突与尚未解决的问题 |
| 格局 | 非数值成长、长线续航、规则博弈 | 每阶段增加的认知、责任与行动权限；旧世界怎样继续参与 |
| 来历 | 表层锚点、身份马甲、纪元断层 | 主角如何接上已定历史与规则，身份代价和最初可知边界 |
| 对抗 | 生态位垄断、规则博弈、世界暗面 | 多方各自合理却难以兼容的目标，胜利如何改变利益结构 |

其他创意门沿通用方法库轮换；方法只辅助本门决定，不能代替题材、视角、关系或命名本身。结构门由引擎即时给档位，不使用创意方法。

### 从脑洞推到大世界

先选一条根规则，逐层问它的后果，不急着起境界与势力名：

1. **生活后果**：一个普通人会因此失去或得到什么，第一场冲突能让读者看到什么？
2. **制度后果**：生产、交换、通行、继承或知识由谁控制，依赖谁，谁被排除？
3. **历史后果**：哪次过去的选择形成了今天的边界，谁仍从中获益，谁承担遗留成本？
4. **文明分歧**：不同群体怎样回答同一个生存问题，各自的成功为何可能伤害别人？
5. **终局问题**：主角即使变得足够强，仍不能靠力量代替哪项选择？揭开真相之后还需做什么？

例如，原创推演种子“交通只能沿被共同记住的路径发生”：一次道路失忆造成眼前危机；教育与档案由此影响贸易和边界；不同文明保存历史的方式互相依赖，也可能冲突；终局可以追问哪些历史应被共同保存、又由谁付出代价。这只演示因果推演，不是默认世界、固定剧情或新的必填规则。

正统路线是同等合法的答案：根规则可以取类型读者熟悉的经典框架（宗门修行、灵气复苏、行业竞争、庙堂博弈），五问照样答满，靠执行与兑现密度与同类平均线拉开差距。为怪而怪不是开书要求；一组方案里常规与高概念并存，好过全组猎奇。

世界门把推演收束成五项架构，格局门再倒推抵达终局的路径。每个方案要有可复述的规则、能落笔的入口、持续矛盾与不同代价；不要只把“城池”改成“诸天”、给反派加等级或给旧外挂换名称。历史、文明和终极问题应互相解释，而非互不相关的背景百科。

### 与已选方向的边界

世界和格局先定，主角来历与优势再接入；身份尚未选定时用“主角”指代，不提前锁定姓名、职业。视角确定后的画面沿用其人称，已选无特殊机制就从现实条件和制度中找动力。短篇可展开一段文明历史的切面，宏大不强制等于星海诸天。

已选记录由后门完整读取。方法体现在 `driver` 与 `tradeoff` 的实际故事差异里，不把方法名塞入 `value`。若作者要求推翻已选世界，返回对应门再选；不得在后门偷偷改写。记录结构和逐字传递由引擎检查，创意质量与因果合理性由当前设计者在原任务内判断，卷纲、章纲继续完成前置核验。

## 卷级转折方法

方法清单在 `contracts.VOLUME_TURNS`，用于卷纲与章纲。按本卷职责和题材选择方法，检查变化是否提前产生后果，不强制每卷使用全部方法或在精确半程翻盘。

| 方法 | 做法 |
|---|---|
| 卷中转折 | 在卷半程安排关键翻盘，改变后半卷的对抗走向 |
| 代价递进 | 卷内分段支付不可替代之物（名誉、靠山、同伴），换取核心真相 |
| 对手揭露 | 前期明面阻力实为棋子，真正的对手在中期浮出水面 |
| 线索回收 | 前期的闲笔或次要人物在卷尾成为决定胜负的关键手 |
| 双线演进 | 核心对手在幕后推进自己的目标，与主角线交错施压 |

设计节点用 `id/kind/purpose/ending_condition/required/window` 表达职责与收束条件，跨卷线路用 `continues: true`；节点与章号窗口规则见 [叙事推进](narrative.md#卷纲)。回收线索前核对原文和已成立证据，不临时补造过去。**伏笔是承诺，要进账**：在卷纲 `hooks` 里登记窗口与 `required`/`continues`，章纲用 `plant`/`payoff` 两个动作执行；`hook_refs` 只用于中途承接已经埋下的承诺，不新增动作。规则见 [伏笔账](narrative.md#伏笔账卷纲声明章纲执行)。

## 创意推演原则（自检）

- **差异化与商业卖点**：在经典框架里找微创新切入点（新生态位、反套路冲突、新奇职业），不照搬类型套路，也不为不同而不同。
- **世界守恒**：任何非常规能力或机制必须有来源、上限与代价；没有特殊机制的项目也遵守其物理、社会与信息边界。
- **生态位与动机自洽**：利益驱动一切，没有纯粹工具人；人物行为扎根于认知视界与处境，不为推剧情降智。
- **主线贯穿**：开书就确立贯穿全书的明确主线与因果链，各卷挂载其上——读者任何阶段都清楚主角在为主线的哪一步而战。
- **闭环收敛**：脑暴不以聊天为目的，每次推演收敛为可签发的方案或条目。

## 名字与称呼

主角名在主角门确定，后续人物在章纲 `new_entities` 里补充档案；当前字面限制见任务 `policy`，修改入口见 [运行](runtime.md)。可以先用职位、特征或外号出场，新身份及关系按章纲声明、由正文与投影状态落地；不能覆盖既有称呼或把候选经历冒充已成立历史。关系门决定核心张力，推进门承接主要对抗；书名在最后选定，与承诺、终局和文风相称。
