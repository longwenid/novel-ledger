# 返工与成本

本文维护减少返工和派工材料的工程原则。历史运行数据见 [验收记录](../validation/archive/results.md)，当前测量方法见 [验证](validation.md)。

## 判据前移与单一来源

- 章纲先模拟资源、位置、知情、时钟、人物、节点、线路与伏笔状态链；不合法的设计在动笔前拒绝。
- 执笔提交同时检查漂移、字数、字面规则、`lint` 和文风代理指标。`check`、`preflight` 与 `submit` 共用校验，前两者回滚试算。
- 字段、简报和模板从同一规则表派生；设计模拟与正式事实结算共用事件规则，避免两套实现逐渐分歧。
- 可选 `ledger` 行验算算式并核对跨工件同键同值；状态增量负责变化。自然语言中的任意数字关系不在这项保证内。

## 返修与收敛

设计提交被拒时保持原任务，按具体错误重交，不消耗正文返修额度。正文候选通过信封与结构校验后，机械问题进入有界返修；失败稿保留，不能伪装成正式稿。

世界模型候选被拒时，引擎把整份候选与逐条拒收理由暂存在任务上（`world_rejection` 暂存键）：下一次 `read` 以 `previous_proposal` 记录交回上一版，重交回执与它逐记录比对，拒收理由点名之外的记录改动或删除会被 `repair_scope` 拒绝；点名识别为空时安全降级，不猜测范围。多轮窄修是设计通道：确实要牵动的第二处，留待下一轮拒收点名。候选通过后暂存清除，新任务从零开始。卷纲返修沿用同一守卫，比对对象是已采纳的上一版卷纲。

每章自动额度为两次 `repair`、一次 `redesign`。额度耗尽或同一问题连续两轮未解决时暂停，由作者选择再修一轮或保留候选并调整约定。换执行者、暂停恢复、预检、改约和历史修订不刷新额度。停止点须有可执行的作者决定通道。

常规写作偏差只返修本章正文，不触发章纲重排。章纲确有矛盾时由作者决定是否修改；作者明确授权的重排优先修正受影响的连续区间。允许保留后缀的任务会冻结 `allow_retained_suffix`；引擎接回原后缀并核验完整状态链及阅读绑定，不相容时扩大范围。具体回执见 [局部重排](narrative.md#有界材料与局部重排)。历史正文修订另受候选分支和作者授权边界约束，见 [修订影响分析](runtime.md#修订影响分析)。

## 材料与派工成本

- 每份必读材料应对应任务中的实际决定；完整来源保留补读入口，正文和证据不截断。
- 等待提交与续租由 `watch` 在引擎进程内完成，主干处理派工和需要作者决定的动作。
- 主控恢复使用只读 `diagnose` 汇总当前任务、版本与执行状态；安全交接点由宿主压缩或更换模型上下文，源码排障单独处理，避免每次机械操作重带全部排障历史。引擎摘要不证明已经清理模型历史。
- 正文用文件工具可靠落稿，完整检查报告一次收集当前问题，再局部修改；不将长正文反复嵌入命令引号。已有读取、身份注入和校验入口优先复用，不通过猜数据库或内部模块恢复。
- t0/t1 按 `PIPELINE_SHAPES.merge_chapter_outline` 合并卷纲与章纲派工，两个契约仍分别校验。
- 测量分别记录首稿前规划量、全书规划量、派工次数与必读字节。`all` 与 `rolling` 的范围差异不能算成同范围成本收益；工程字节数也不能冒充模型计费 token。

快速模式用一个 Worker 连写最多十章，每章仍保留独立任务和入库事务；减少的是新会话启动与相同必读来源的重复读取，不减少章节校验。首章、卷界和作者停点使分组提前结束。完整操作见[快速无人值守](runtime.md#快速无人值守十章一组)。

前章全文逐章按哈希冻结，组内只补新增或改变的来源；换上下文或明确全量重读仍交付完整必要正文。场景材料引用已交付的章纲，不再重复嵌入同一计划。地点和知识的进一步精简仅用于按固定章纲执笔、返修，且以完整场景依赖声明为前提，保留当前站位、移动与路径条件、对白话题、知情变化和显式读取；依赖不完整或正在规划、重排时保守保留材料，不能以旧起章的依赖裁掉后续章节所需来源。

独立核验的等待同样交给引擎；正在首读或比较不重复唤醒主控派读者。读者只接收当前交付原文的哈希及历史范围，远章从冻结历史补读，不逐次传输整本书的哈希清单。核验覆盖与独立首读顺序保持原规则；费用和派工统计须计入独立读者，不能把执笔会话的减少等同全流程收益。

## 验证边界

自动校验覆盖声明、投影、引文和可量化文风特征。它不判断动机、情节张力或伏笔兑现的阅读效果；机械通过仍不能证明正文在语义上落实了章纲。这些问题需人工抽读、离线盲测或另行修订。

新增规则应来自可复现缺陷，先明确覆盖范围，再纳入对应校验与回归测试。真实连续创作质量、宿主隔离和费用使用真实运行证据验收，不能由合成回执推断。
