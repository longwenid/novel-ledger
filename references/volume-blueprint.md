## 五判别式（单侧默认档：答不上＝改设计或说明理由，不是拒稿）

| 判别式 | 判别问句 | 落点 |
|---|---|---|
| BP-1.1 真职责：卷必须改变对抗条件 | 本卷对付谁变了（对手出局/升格/换人）、用什么筹码变了（身位/体制/资源量级）？非终卷自检：抽掉本卷，后续哪一卷首先不成立；终卷／单卷改问：哪些核心承诺或人物结局无法完成 | purpose |
| BP-1.4 升阶＝身位/结构不可逆改变 | 判据是「换对手/换筹码/换战场/换规则」至少其一；修为层数、存款数字的增长只是数值推进，不得记作 stage 升阶 | stage |
| BP-2.3 不可逆点：撤掉后对抗回不回得去 | 写出「撤掉该事件后，哪些后续章或结局不成立」；写不出＝本卷没有实质后果 | arc、turns |
| BP-2.5 真伪转折（单侧） | 该转折实际改变了哪项对抗条件（换对手/筹码/战场/规则/己方阵容），且后半卷持续生效？只让局面更紧的事件＝推进，删出 turns | turns |
| BP-3.4 承诺具体性（单侧） | 读者能否指着载体复述、并在 payoff 到来前一直记得「等着看什么」？hooks.text 须有明确对象物/规则条款/知情范围/完成判定；写不出载体的承诺删掉重写 | hooks.text |

## 八反模式（命中＝在原任务内改进或说明理由；证据为正对照，详见全量版卷8）

| 反模式 | 识别特征（一句话） |
|---|---|
| BP-8.1 伪转折 | 升级不换条件：五项对抗条件一项没换、后半卷对抗手段照旧，却写进了 turns（反噬 BP-2.5） |
| BP-8.2 空泛承诺 | 「另有隐情」式：悬念指不出对象物/条款/范围/判定，payoff 前读者无从记起（反噬 BP-3.4） |
| BP-8.3 卷末只闭合不撬开 | 仅非终卷自查：卷末全收平、下卷开局无后果目标或残留可接（反噬 BP-7.4） |
| BP-8.4 跨卷承诺缺承接 | 到了约定兑现窗仍无承接或兑现安排；后卷用原 id 承接，不复制声明、不重复 plant（反噬 BP-5.1） |
| BP-8.5 资源白增白耗 | 显著增减挂不到具体转折/高潮，或摆幅与卷职责错配（挫败卷大赚、结算卷巨亏）（反噬 BP-6.4） |
| BP-8.6 换图无绑定 | 到了新地图但对抗条件不变，不绑定升阶事件或新线路，换图沦为观光（反噬 BP-6.6） |
| BP-8.7 时钟不自洽 | 事件时长、已选期限与实际安排矛盾＝漏算过程、跳档或并行关系（反噬 BP-7.6） |
| BP-8.8 节点悬置 | 节点写不出「达成即收」的一句话判定，窗口无限拉长、章数虚耗（反噬 BP-4.4） |
