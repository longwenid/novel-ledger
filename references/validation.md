# 验证

工程测试用临时新项目及明确标记的合成回执，不调用付费模型，不作为文学成果。

```bash
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests -v
python3 <skill-creator>/scripts/quick_validate.py ROOT
python3 validation/measure.py --out /path/to/metrics.json
```

quick_validate 属宿主自带工具，路径按本机实际安装替换；它是可选的附加校验，缺失时不影响上面的测试与测量。Windows 控制台默认 GBK：测试与 CLI 自身按 UTF-8 读写，但外部校验脚本可能仍按本地编码读文件，此时对全部命令加 `PYTHONUTF8=1`。

验证提交与回滚、幂等、首读隔离、真实会话身份声明、有限返修、作者版本认可、事实结算、跨章覆盖、修订改约、恢复、原子初始化、真实子进程和未知库拒绝。依赖守护包含函数内 import，纯规则不得依赖 I/O。

测量源码、模块、完整依赖图和必读完整记录字节。增加未引用未来节点时，必读材料应完整且不无故增长，全设计仍可按哈希读取。字节不等于计费用量，代码精简不代表所有旧优化行为等价。

真实文学评估选连续完整章节和真实卷界，固定题材、体量、模型及审稿条件，独立盲读比较人物声音、动机、代价、因果、重复解释和兑现；记录实际返修、人工干预、总用量及费用。定位变体的预期保留在私有文件，评审只读正文。

原稿不是金标准，误报需独立裁决；修稿重新首读，确认缺陷消失且无新损失。模型历史隔离、后台运行和旧项目迁移分别验收，不以合成回执或新进程代替。

新增叙事测试使用显式跟踪约定；旧协议夹具显式关闭跟踪，另验旧在途清单兼容。测量同时覆盖未引用未来节点、连续依赖链和 20/100/500 章覆盖树；查看 tracked_causal_context/review_trees，不能把输入字节换算为真实 token 费用。

编辑能力使用显式 editorial_features=true 的独立工程夹具，覆盖成长重核、场景意图、补丁合成和回滚、改案保留原稿、独立核验后重新首读、卷末有界补写、原子修订、根预算继承、终审来源查漏与快照交付。旧协议夹具显式关闭新能力，冻结旧清单不被追补。离线盲测与实际用量命令见 [编辑能力](editorial.md)；盲测先冻结首读，原稿警报只有独立裁决后才计误报。合成回执仍不证明文学质量。

历史测量 history_transport 使用 20/100/500 章独立存储夹具，500 章含至少150万合成汉字。记录目录入口字节、原全量摘要/事件索引字节、首次构建及复用、实际读取事件页数、无命中最坏扫描和最早章完整补读；不把夹具称为已写审完本。行为测试同时覆盖目录损坏、旧任务索引、冻结边界、分支共享前缀、承诺证据关联、旧事件解释不变和补读量留痕。

## 真实长篇验收

在作者授权的独立小说项目中固定模型、题材、篇幅、写审条件和验证档位，保存引擎版本、作者约定及准确交付快照。百万字目标须实际写审至授权终点并通过 complete/deliver；短篇试跑只算预验收。验收分别记录：

- 连续性：人物/物品再次出现时的远期承诺、跨卷因果和揭示，抽检原文与事实事件是否一致；漏报和错误关联由独立裁决记录。
- 多线与呼吸：盲读连续完整章节及真实卷界，检查主线是否可感、支线的作用、暗线线索与揭示、高潮余波和静章变化；用原文说明得失，不以固定推进间隔、角色标签或张力分数当金标准。
- 效率：分别保存派工/补读字符量、宿主实际 token/缓存日志、失败调用、返修次数及人工干预；对照版本应固定相同来源和模型条件。没有计费日志则费用未知，不从字节换算费用。

人物对白样本库、主线间隔提醒与其他节奏辅助先在同条件盲评中验证收益及误报，再决定是否引入；不把尚未证实的建议直接变成拒绝规则。
