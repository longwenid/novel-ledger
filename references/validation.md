# 验证

工程测试用临时新项目及明确标记的合成回执，不调用付费模型，不作为文学成果。

```bash
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests -v
python3 <skill-creator>/scripts/quick_validate.py ROOT
python3 validation/measure.py --out /path/to/metrics.json
```

quick_validate 属宿主自带工具，路径按本机实际安装替换；它是可选的附加校验，缺失时不影响上面的测试与测量。Windows 控制台默认 GBK：测试与 CLI 自身按 UTF-8 读写，但外部校验脚本可能仍按本地编码读文件，此时对全部命令加 `PYTHONUTF8=1`。

验证提交与回滚、幂等、首读隔离、真实会话身份声明、有限返修、作者版本认可、事实结算、跨章覆盖、修订改约、恢复、原子初始化、真实子进程和未知库拒绝。依赖守护包含函数内 import，纯规则不得依赖 I/O。

测量源码、模块、完整依赖图和必读完整记录字节。增加未引用未来节点时，必读材料应完整且不无故增长，全设计仍可按哈希读取。字节不等于计费用量，代码精简不代表所有旧优化行为等价。

真实文学评估选连续完整章节和真实卷界，固定题材、体量、模型及审稿条件，独立盲读比较人物声音、动机、代价、因果、重复解释和兑现；记录实际返修、人工干预、总用量及费用。定位变体的预期保留在私有文件，评审只读正文。

原稿不是金标准，误报需独立裁决；修稿重新首读，确认缺陷消失且无新损失。模型历史隔离、后台运行和旧项目迁移分别验收，不以合成回执或新进程代替。
