## 2. 简报新增字段要点

- **卷纲**：`hooks` 必填数组（可空）；每条 id 全书唯一（与 node/thread 同命名空间，跨卷续用 `continues=true` 且 `required=false`）、`text` 是具体承诺、`plant` 必须落在本卷章号区间、`payoff[0] >= plant[1]`、越过卷末必须 `continues=true && required=false`、`required=true` 卷末必须兑现；`style.trend` 必填写清走向，`style.window` 可逐项覆盖 `style_window`。
- **章纲**：`hooks` 必填数组，只有 `plant`/`payoff` 两个动作；同一 id 各一次、payoff 不早于 plant（同章可先埋后兑）、各自落在卷纲窗口内；中途再提用 `hook_refs`（未埋就承接会被拒）；`style` 的 `pov` 与契约一致、`rhythm` 必填、`dialogue_ratio` 0~1 可选、`notes` 写例外。
- **write**：`drift_check` 现在包含 `hook` 行（planned.action）；`self_check` 必须逐条点名 pov/rhythm/dialogue_ratio 落在哪几段，并说明 plant/payoff 在正文的落点；并写明"机械指标只保证一致与可核对，不证明好看"。
