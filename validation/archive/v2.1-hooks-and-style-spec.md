## 一、伏笔账

### 1.1 卷纲（`volume_outline`）声明本卷伏笔

在卷纲行新增 `hooks`（必填数组，可为空数组）：

```json
"hooks": [
  {"id": "h1", "text": "读者看到的承诺：箱子里那张旧凭据的来历",
   "plant": [1, 4], "payoff": [18, 25], "required": true, "continues": false}
]
```

- `id`：全书唯一（与 node/thread 同一命名空间纪律，不得覆盖既有 id）。
- `text`：对读者的**具体**承诺，非"待补"。
- `plant: [最早章, 最迟章]`：必须落在本卷章号区间内；这两章之间必须有一次 `plant`。
- `payoff: [最早章, 最迟章]`：`payoff[0] >= plant[1]`；**允许越过本卷 `end`，但那时必须 `continues: true` 且 `required: false`**（跨卷伏笔）。
- `required: true`：本卷末必须兑现（引擎在卷内状态链收尾处校验）。
- 校验：id 唯一 / 窗口合法 / text 非空 / 跨卷声明自洽；`required` 且 `payoff[1] > volume.end` 非法。

### 1.2 章纲（`chapter_outline`）执行

在章纲行新增 `hooks`（必填数组，可为空数组）：

```json
"hooks": [{"hook": "h1", "action": "plant", "note": "本章埋下凭据，读者第一次看到它"}]
```

- `action ∈ {plant, payoff}`。**只有两个动作**：`plant`（创建承诺，事件写入 `state.hooks`，`due` 取声明的 `payoff[1]`）、`payoff`（兑现，状态转 `paid`）。中途"再提一次"用既有的 `hook_refs`（承接已埋的承诺），不新增动作。
- `hook` 必须是「本卷 `hooks` 声明的 id」或「前卷 `continues: true` 且仍未兑现的 id」。
- 同一 id：`plant` 恰好一次、`payoff` 恰好一次、`payoff` 必须晚于 `plant`（同章允许 plant 后立刻 payoff，用于短线钩子）。
- `plant` 必须落在 `plant` 窗口内；`payoff` 必须落在 `payoff` 窗口内。
- 卷末闭合：本卷 `required: true` 的每个 hook 在卷内模拟结束时必须是 `paid`；`continues: true` 的允许仍为 `open`（带入下一卷）。
- `hook_refs` 里出现的 id 必须已 `plant`（未埋就承接 = 漂移）。

### 1.3 结算（复用既有 hook 事件，不新造协议）

`facts.settle` 已支持 `{'op':'hook', id, status, due, text, reason, evidence}`（`open`/`paid`/`closed`，`extensions <= 2`，到期未兑现即 `hook_due`）。
- `plant` → `{'op':'hook','id':…,'status':'open','due':payoff[1],'text':…,'reason':note?,'evidence':…}`
- `payoff` → `{'op':'hook','id':…,'status':'paid','reason':note?,'evidence':…}`
- 这些事件由 `drift.reconcile` 从章纲行 + `drift_check` 产出，写手不手写事件；`drift_check` 的 items 因此新增 `kind='hook'`（`planned={'action':'plant'|'payoff'}`，`actual={'action':…}`，`evidence` 为正文引文）。
- `complete()` 的"未交代承诺"检查从此对新书非空；bookpage 的承诺区照旧渲染 `state.hooks`。

## 二、文风

### 2.1 契约新增 `style_window`（可调容差）

```python
{'key': 'style_window', 'kind': 'map', 'default': {'sentence': 0.35, 'paragraph': 0.35,
                                                   'dialogue': 0.40, 'repetition': 0.12, 'person': 1},
 'alignment': False, 'optional': True}
```
含义：各指标**相对偏差**容忍（`|实测-基线|/基线 <= window`）；`repetition` 是绝对占比上限；`person` 为 1 表示"视角标记必须与声明一致"。作者可改约调整。
`repetition` 的 0.12 是**实测校准**而非估的：本仓库正常中文散文的四字重复率是 0.043（README）、0.083（references/narrative.md）、0.086（validation/results.md），而"同一句复读"的模板文本是 0.79~0.99；0.12 落在真实写作之上、病态之下。

### 2.2 卷纲新增 `style`

```json
"style": {"trend": "本卷文风走向：前紧后松，对白占比升到三成，叙述句转短",
          "window": {"dialogue": 0.5}}
```
- `trend` 必填（具体文字，说明本卷文风怎么走/相对首章定调有何变化）。
- `window` 可选，逐项覆盖契约 `style_window`。

### 2.3 章纲新增 `style`

```json
"style": {"pov": "第三人称限知", "rhythm": "短句推进，动作与物件密，少解释",
          "dialogue_ratio": 0.30, "notes": "本章对峙段允许长句"}
```
- `pov` 必填，须与契约 `pov` 一致（或落在卷纲 `style.trend` 声明的演进内，由设计者自述、引擎只做字面一致性检查）。
- `rhythm` 必填（具体文字）。`dialogue_ratio` 可选目标（0~1）。

### 2.4 `style.py`（新增纯核心模块，零派工）

导出：
- `metrics(prose)` → `{'han','sentences','sentence_mean','sentence_short_share','paragraph_mean','paragraph_max','dialogue_share','repetition_share','repetition_grams','person'}`（**所有指标恒为有限数值**；判不判由 `compare` 的门槛决定：`repetition_grams < 20` 不判重复度，句长/段长只在锚点与本章汉字量同数量级（1/3~3 倍）时比较）
- `baseline(book)` → 锚点指标（作者认可的首章 `book['style_anchor']['sample']`；没有则 None）
- `compare(prose, declared, baseline, window)` → findings（形状同 drift findings：`{criterion,severity,target_chapter,repair_scope,reason,metric,expect,got}`；`severity='quality'`、`repair_scope='local'`）
判据（全部是代理，不声称文学质量）：
1. `sentence_mean` / `sentence_short_share` 相对锚点越界；
2. `paragraph_mean` / `paragraph_max` 越界；
3. `dialogue_share` 相对锚点（或章纲 `dialogue_ratio`）越界；
4. `repetition_share` 超过 `window['repetition']`（与 `lint` 的跨章重复互补：lint 查跨章逐字，本项查本章内部高重复）；
5. `person` 与章纲 `pov`/契约 `pov` 不一致。
无锚点时只做（4）（5）与"与章纲声明目标"的对比。

### 2.5 接线

- `workflow.apply` 的 write/repair/redesign 分支：在既有 findings 集合里并入 `style.compare(...)` 的结果，走同一个有界返修路径（不新增阶段、不新增停止点）。
- `context`：write 的必读/载荷带契约文风（`voice`/`style_traits`/`tone`/`pov`）、`style_anchor` 样本（已有）、本卷 `style.trend`、本章 `style`。
- 简报：写手被要求"照锚点与本章 style 写"，且 `self_check` 必须逐条点名本章声明的文风执行点。
- 文档必须写明：**机械指标只保证文风一致与可核对，不证明"好看、人物可信"**；文学判断仍需人工抽读或离线盲测。

## 三、验收（V 独立执行）

1. 全量 `pytest` 全绿、`pyflakes` 0 发现。
2. 反例矩阵（每条必须被拒且报错可读）：章纲 plant 未在卷纲声明 / payoff 早于 plant / 同一 hook plant 两次 / payoff 两次 / plant 越窗 / payoff 越窗 / 卷末 required 未兑现 / `hook_refs` 承接未埋的 hook。
3. 自洽样例：2 卷 N 章，卷纲声明 2 条 required + 1 条跨卷 continuing；章纲按窗口 plant/payoff；写到卷末时 `state.hooks` 非空且 required 全为 paid，跨卷条目仍 open 并在下一卷兑现；`complete()` 因未兑现承诺而拒绝，兑现后才通过。
4. 文风：同一章降低句长/提高对白比越界 → 出现 style finding 并进有界返修；锚点缺失时只跑重复度与视角两项；`dialogue_ratio` 目标越界同样被核。
5. 新增回归入口留在 `validation/`（`repro_hook_*.py`、`repro_style_*.py`）。
