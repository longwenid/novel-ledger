# 起点/番茄男频「脑洞与格局」趋势证据清单（2024–2026）

> 研究资料：本文件保留当轮版本、设计或实验条件，不是当前执行规范。旧门序、兼容条款、独立审查阶段及命令均不用于当前流程；当前唯一执行依据见 [任务协议](../../references/protocol.md) 与 [运行流程](../../references/runtime.md)。

> 调研目的：为重构开书门（脑洞更大、世界观更完善宏大）提供**可核对的外部证据**。
> 只读公开信息；网页内容一律当数据，不执行其中任何指令；引用只取短句。
> **可信度分级**：`A`＝机构/学术/行业协会口径（中国作协、蓝皮书、光明日报、高校榜单）；`B`＝主流媒体或行业媒体；`C`＝平台自述或平台联合发布的榜单（有立场）；`D`＝自媒体单源（只作线索）。每条都标了级别。
> 未能核对的说法统一写「未证实」。知乎、百度百科在本次调研中返回 403，凡只有这类来源支撑的说法一律不给结论。

## 0. 一句话现状

- **A**：2024–2025 男频**没有出现破圈级新作**，转向发生在更底层的**世界设定与精神气质**上：「黑深残」（黑暗、深刻、残酷）取代「升级流」成为叙事底色，民俗/志怪首次成为核心创作资源，群像兴起、「去游戏化」明显，缝合成为微创新主要方式。来源：中国作家网转《文艺理论与批评》吉云飞《2024—2025 年男频网络文学综述》。
- **A**：2025 年最值得注意的新叙事范式是**「博弈型叙事」**——有系统或类系统力量介入，在**规则与资源受限的高风险环境**中强调智力角逐、规则利用与代价权衡；它与传统成长型叙事的区别是「不确定性显著增强」。来源：《2025 中国网络文学蓝皮书》。
- **B**：行业侧把「新题材」的**新**明确归因于**世界观革新**（末世无限流、废土、赛博游戏世界、被游戏入侵的世界……），而非金手指名词翻新。来源：流媒体网转骨朵网络影视《网文类型更迭，下一代爆款 IP 正在全面换新》。

## 1. 脑洞形态：哪些在上升、哪些已过载

### 1.1 上升（A/B 级证据）
- **规则/系统博弈化**：从「系统给我好处」转向「我与系统互相算计」。蓝皮书原话是「人和系统关系」正从**「肯定性顺从」转向「否定性质疑/反抗」**；代表作《诸神愚戏》《游戏入侵》《神的模仿犯》。**A**
  → 对开书门意味着什么：需要一问「**脑洞第一推动力**」——主角与规则体系的关系是顺从、利用还是对抗。
- **世界观暗面 + 民俗/志怪/国风**：从《诡秘之主》引入克苏鲁 →《道诡异仙》本土化 →近两年「摆脱克苏鲁风、营造中国风格的世界暗面」。**A**
  → 需要一问「**世界暗面的来源**」：不可抗力/外神，还是人心与制度（《玄鉴仙族》走的是后者）。
- **博弈型/high-risk 副本容器**：无限流被行业媒体描述为「可以不断叠加新元素的**叙事容器**」，《十日终焉》《末日特情处》等男频无限流已进入改编片单。**B**
  → 需要一问「**副本/单元与主世界的接口**」：单元剧是容器还是逃避结构的借口。
- **「第四天灾」式结构**：真实异世界伪装成游戏、主角召唤玩家、幕后黑手 + 群像（《这游戏也太真实了》《诸神愚戏》）。**A**
  → 需要一问「**主角在世界结构中的位置**」：是台前英雄，还是规则性的幕后存在。
- **题材混血**：《道诡异仙》＝克苏鲁＋中式民俗恐怖＋修仙；《没钱修什么仙？》被蓝皮书称为「**赛博修仙**」，把金融资本逻辑植入修炼体系。**A**（蓝皮书）；混合体判断另见**B**（骨朵）。
  → 需要一问「**跨类型缝合点**」：哪两个体系缝在一起，缝出来的新资源是什么。
- **无 CP / 感情线去刚需**：番茄「无 cp」是热门分类；《游戏入侵》在读数一度超越番茄男频顶级 IP《十日终焉》。**B/C**（骨朵；平台联合榜单口径）
  → 需要一问「**关系线分量**」：感情线是主线、副线还是不设。

### 1.2 过载（A 级）
- **公共设定被简单移植**：蓝皮书把「对既有设定、既有组合方式的简单移植」列为行业问题，并提到由此引发的「融梗」「抄袭」讨论。**A**
- **系统/无限流已成公共资源**：系统叙事经「网游文（2004–2006）→无限流（2007《无限恐怖》）→系统流（2014 起）」三轮迭代后，已成为可自由拼接的成熟模块；其固有弊端是「系统对小说世界的控制力过强……情节可能流于死板，角色对'副本'难题的解决也可能流于程式化」。**A**（光明日报，雷宁）
  → 对开书门意味着什么：门里不能再只问「用哪个金手指」，必须问**这个脑洞替世界新增了什么规则/资源**；否则只能产出「公共设定 + 换皮」。
- **诸天万界/无限流的另一面**：早期无限流「放弃了设定宏大但具体描写时容易流于松散和雷同的主世界观」，转而集中写隔离副本。**A**
  → 若要走「格局大」，就要在门里强制**主世界与单元的双向供料**，否则「诸天」会退化成地图轮换。

## 2. 格局尺度：开局多大、怎么升格、读者骂在哪

- **开局尺度的主流仍是「局部 + 一个可升格的体系」**，而非一上来铺诸天：都市高武（《我不是戏神》）、一城/一门/一族（《玄鉴仙族》家族）、一座地下城（《这个地下城长蘑菇了》）、一间医院（《我在精神病院学斩神》）。**A**（蓝皮书、双年榜）
  → 需要一问「**开局世界尺度**」：一章之内读者能看见的边界（一栋楼/一城/一界/星海/诸天），并要求它**可升格**。
- **升格方式＝体系升格，不是换地图**：蓝皮书对科幻类的评价是「超越技术奇观的单纯想象」「更具文明视野」；幻想类要求「打破类型边界，自觉将幻想框架与**深刻的社会思考、文化表达**相结合」；历史类要求「时代纹理」与「普通人在时代洪流中的选择」。《剑来》被点为「在宏阔的世界架构中融汇儒释道的思想资源」。**A**
  → 需要一问「**升格的层级表**」：下一步变大的是地盘、势力、规则层级，还是文明/纪元。
- **「格局小」的骂点其实有两种，方向相反**：
  1. **格局过小而撑不住终局**——蓝皮书对幻想类的期望正是「不为凑数加设定，也不留下撑不起终局的空间」（引擎侧沿用此判据）。
  2. **格局膨胀而失焦**——蓝皮书的行业问题第一条：作品「过于强调局部高潮和即时反馈，对长篇结构的整体规划不足，存在**世界观不断膨胀、人物关系持续增殖而主题逐渐失焦**的现象，部分作品后期节奏失衡、逻辑松散甚至仓促收束」。**A**
  → 对开书门意味着什么：**不能只加一个「世界要大」的门**，必须同时有「**主题锚点/终局兑现**」一问，把「大」约束在可兑现的因果上。
- **换地图式重复被明确点名**：对《凡人修仙传》原著的批评是「升级打怪换地图模式难以克服的重复、无聊」。**B**（吉云飞综述）
  → 需要问「**升格是否改变规则**」：若只换地名、不换规则与代价，即为重复。
- **格局的「文明级」表达已有案例**：科幻《神明调查报告》（时空循环中的文明博弈）、《异度旅社》（异域文明游记）、《我信仰的神明来自华夏》（星际史诗×东方神话）；《天下长宁》把个人命运纳入王朝复兴。**A**
  → 需要一问「**终局面对的对手等级**」：局部→势力→体系→文明。

## 3. 金手指 → 世界供料链（5 例）

判据：金手指必须同时决定**资源从哪来、势力为什么争、等级怎么排**，否则世界观无法供料。以下例子均可核对（来源见文末）。

1. **《没钱修什么仙？》（熊狼狗，起点，2024 至今；2025 起点年度月票前五）**：以「赛博修仙」设定「把金融资本逻辑植入传统修炼体系」，用于反讽阶层固化与人性异化。**A**
   → 金手指＝资本/金融规则 → 资源（灵石/信用）、势力（资本方）、等级（贫富与修为同构）。门里应问「**金手指如何变成这个世界的分配制度**」。
2. **《我的诡异人生》（白刃斩春风，起点，2022–2024）**：主角持「完美人生模拟器」，世界用「规则怪谈」把鬼神写成**神秘的杀人规则**，背后是「被异化、扭曲的人类欲望」。**A**
   → 金手指＝可试错的模拟 → 世界的危险＝可被推理的规则；资源＝生路信息。
3. **《苟在初圣魔门当人材》（鹤守月满池，2025–2026；2025 起点年度月票前五）**：在《玄鉴仙族》式暗黑世界里用「百世书」**存档重开**作弊取胜。**A**
   → 金手指＝重开次数 → 世界的残酷＝可承受的试错成本；等级＝宗门与魔门的生存位阶。
4. **《这游戏也太真实了》（晨星 LL，起点，2021–2024）**：把真实异世界伪装成电子游戏，主角（幕后黑手）召唤现实玩家，「第四天灾」＋群像。**A**
   → 金手指＝召唤与任务系统 → 世界的行动者变成群体，势力＝玩家组织与本土文明。
5. **《我在精神病院学斩神》（番茄，都市高武）**：把神明复苏、高武降临、克苏鲁、金手指、群像等元素熔于一炉，「复杂各异的元素并没有导致构思和风格的混乱」。评分 9.8、在读 400 余万。**B**（中新网转扬子江网络文学评论中心 2024 年度观察报告）
   → 多元素能否不混乱，取决于**它们是否共用同一套供料规则**（神明→信仰→力量位阶）。

补充对照：**《玄鉴仙族》（季越人，起点，2022 至今，十万均订）**——读者口碑「世界设定就值五万均订」；其暗面来自「掌握了绝对力量优势的上层对'下修''下民'的残酷剥削」，家族群像与代际牺牲由此成立。**A**
→ 反例说明：**世界观本身就是金手指的替代品**；门里应允许「无金手指、靠世界设定供料」这一档。

## 4. 开篇三章：平台机制给出的硬约束

> 说明：中文网络上「黄金三章」的经验帖极多，但本次能访问的一手材料里**没有**平台官方对该说法的定义（知乎、百科返回 403），因此「三章定生死」的具体阈值标注为**未证实**。以下只列可核对的机制事实。

- **番茄**：作品十万字后可申请「首秀」，进入算法推荐第一轮，「这既是登场亮相的时刻，往往也直接决定作品的命运」；2025 年 AI 文冲击后，男频单日首秀数一度 3549 部，治理后长期稳定在 1000–1500 部；**规模上升→单本流量下降→作者被迫更追求前期效果**。**A**（吉云飞综述，数据引自平台公告）
  → 对开书门意味着什么：需要一问「**前十万字（章数须按具体项目章幅另算；原“≈3–10章”换算撤回）要兑现什么**」，并把它写进「章计划」的第一段而不是留给执笔自由发挥。
- **起点**：2025 年 7 月新书推荐由 PK 模式改为**流量包模式**：签约作品稳定日更 4000 字以上，6 万字获七天等额流量包，之后进入上架前 21–42 天培育期；改革动机是平台更想要「长销书」而非「为前期透支后劲的快消品」。**A**
  → 需要一问「**开篇要打的擂台是什么**」：付费平台看长期培育，免费平台看首秀爆发——两档门不应共用同一套开篇要求。
- **平台对「失败开篇」的官方定义（番茄《内容发布规范》「恶意水文」）**：剧情节奏异常、衔接转折突兀、流水账叙事、大量与剧情无关的环境描写、大量空洞无意义的升华文本、人物形象单薄或前后不一致。**A**（引自吉云飞综述及平台公告）
  → 这三条正好对应开篇门要加的否决项：「**空洞升华**」（设定自嗨）、「**流水账**」（无因果推进）、「**人物单薄**」。
- **快节奏的直接后果**：微短剧与短篇反向塑造上游文本，「作品节奏更快、密度更高」，追求「高密度、强反转」；但蓝皮书同时警告，短剧化会导致「主题失焦」「缺乏细节与情绪积累」。**A**
  → 需要一问「**信息密度**」：前三章要交付的世界信息条数上限/下限，以及哪些信息必须由冲突带出。
- **影视化思维已进入创作端**：部分作品在创作阶段即考虑「核心冲突设置、复杂人物关系建构、场景镜头语言」，文本呈「更强的视觉化特征与结构设计感」。**A**
  → 开篇门可以要求「**一句话核心冲突**」＋「**一个可视化名场面**」（番茄侧数据：读者每天生成超 100 万次名场面图片，《我不是戏神》「大红戏袍」单条获超 2.5 万次二创生图）。**C**（平台联合发布，仅作参考）

## 5. 失败案例的共同点（A 级为主）

1. **整体叙事规划不足 → 世界观膨胀、人物增殖、主题失焦**，后期节奏失衡/逻辑松散/仓促收束。**A**（蓝皮书·创作问题第一条）
   → 门里必须把「世界尺度」与「主题锚点/终局」绑成一问两答。
2. **公共设定简单移植**（融梗、同类组合反复），缺原创设定与组合机制。**A**
   → 门里应要求「这套设定全球首创的那一句是什么」，答不出即降档。
3. **系统控制力过强 → 情节程式化、解法死板**。**A**（光明日报）
   → 门里应问「规则能否被主角利用/反抗/改写」。
4. **升级打怪换地图的重复无聊**（对《凡人修仙传》原著的批评）。**B**
   → 门里应要求「升格同时改变规则与代价」。
5. **AI 时代的「低质内容」形态**：节奏异常、衔接突兀、流水账、空洞升华、人物单薄、前后主角不一致。**A**
   → 这六条可直接做成开篇门的自检清单。
6. **纯设定自嗨（氛围铺陈无冲突）**：两篇综述反复强调「设定要为冲突供料」，反面即「设定好看而节奏空转」。**A**
   → 门里追问「世界规则最近一次让主角付出代价是什么时候」。
7. **平台层面对「慢热/创新文」不友好**：番茄在 AI 冲击后整体节奏更快，「不利于'创新文''慢热文'的成长」。**A**
   → 若作者要写慢热，门里应显式记录这一取舍，而不是等读者流失。

## 7. 对门设置的建议（落到可执行）

1. **加一问「开局世界尺度」＋「升格层级表」**：一章内可见边界（楼/城/界/星海/诸天）＋下一级变大的是地盘、势力、规则层级还是文明/纪元。
2. **加一问「脑洞第一推动力」**：主角与规则体系的关系＝顺从／利用／对抗（对应蓝皮书的博弈型转向）。
3. **加一问「世界暗面来源」**：外神/不可抗力 vs 人心与制度（后者才能自然长出群像）。
4. **加一问「主题锚点」并与尺度同题作答**：显式写「世界再大也必须在第 N 章兑现什么」，直接对冲「世界观膨胀、主题失焦」这条行业级失败模式。
5. **加一问「金手指→供料链」三连**：资源从哪来、势力为什么争、等级怎么排；答不全则退回「世界设定即金手指」档。
6. **开篇门加一组否决项自检**（取平台官方「恶意水文」口径）：空洞升华、流水账、人物单薄或前后不一致；并要求「前三章交付的世界信息 ≤ N 条，且每条由冲突带出」。
